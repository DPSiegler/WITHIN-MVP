# WITHIN Tests

This folder contains test cases and test results for the WITHIN MVP.

## What we test

- Voice conversation and connection failures
- Disclosure, consent and refusal
- Profile accuracy and user corrections
- Consent-based saving and returning conversations
- Data access isolation and deletion
- Help flows and agreed safety scenarios

## Test record

For each test, record:

- Test ID and date
- Feature being tested
- Steps and expected result
- Actual result: Pass, Fail or Not Tested
- Defects or limitations
- Link to supporting evidence

Testing must use appropriate test data. Passing technical tests alone does not authorise real-user testing.
