# WITHIN Prompts

This folder contains approved, version-controlled prompts created for the WITHIN MVP.

## Working rules

- Only include material created for WITHIN that we have the right to use.
- Record the purpose and version of each prompt.
- Test prompt changes against agreed acceptance criteria.
- Record important changes and test results.
- Do not include API keys, passwords, real user conversations or sensitive personal data.

Prompts remain subject to product, safety and technical review before use.
